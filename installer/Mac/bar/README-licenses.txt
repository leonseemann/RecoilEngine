BAR.app for macOS

This app contains only the Recoil engine (GPL v2 or later, see LICENSE and
gpl-2.0.txt), its pr-downloader and the libraries listed in this folder, each
under its own license (Mesa, LLVM, SDL, OpenAL Soft, ...).

Source code of the engine build: https://github.com/leonseemann/RecoilEngine

The Beyond All Reason game, the BYAR-Chobby lobby and all game artwork are NOT
part of this app. They are downloaded on first start from the official Beyond
All Reason servers and are subject to their own licenses, see
https://github.com/beyond-all-reason/Beyond-All-Reason/blob/master/LICENSE.md
